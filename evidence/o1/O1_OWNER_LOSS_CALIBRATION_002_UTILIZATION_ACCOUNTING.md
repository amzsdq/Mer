# O1 OWNER LOSS CALIBRATION 002 — UTILIZATION ACCOUNTING

Status: IMMUTABLE_SHADOW_ANALYSIS

Recovery experiments should distinguish:
- useful work time,
- bootstrap/authority-read overhead,
- liveness/renewal overhead,
- takeover/reconciliation overhead,
- scheduler overhead,
- idle waiting between actual work sessions.

The 600-second floor improves per-wake useful-work opportunity only if the added time is substantive work. It must not improve reported utilization by reclassifying control/evidence churn as useful work.

For calibration 002, much of the activity is genuine research design/evidence production, but repeated duration-audit markers are control overhead and should be classified separately in any utilization calculation.
