# O1 OWNER LOSS CALIBRATION 002 — WORK_OK DEFINITION

Status: IMMUTABLE_SHADOW_ANALYSIS

For owner-loss recovery, WORK_OK should require evidence of substantive useful work under the new authoritative generation after takeover. Mer should not count these alone as WORK_OK:
- ownership CAS success;
- scheduler verification/update;
- state reconciliation;
- takeover evidence publication.

Those establish WRITE_OK/STATE_OK/WAKE_OK/control recovery. WORK_OK requires the recovered owner to advance the active research/work step and persist corresponding evidence/state.

This prevents recovery plumbing from being mistaken for recovered productivity.
